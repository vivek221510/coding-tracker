# CodingTracker

CodingTracker is a full-stack web application that helps competitive programmers track their progress across coding platforms and compete with friends through squads.

The project was built to provide one place where users can view their coding statistics, monitor progress, create squads, and compare rankings with other members.

---

## Features

### User Authentication
- Register and login
- JWT authentication
- Protected routes

### Profile Linking
- Link LeetCode account
- Link Codeforces account
- Store platform usernames

### Dashboard
- Total solved problems
- LeetCode statistics
- Codeforces statistics
- Contest ratings
- Custom milestone tracker
- Sync platform data

### Squad System
- Create squads
- Join squads using invite code
- Join request system
- Squad member management
- Squad leaderboard

## Installation

### Clone the repository

```bash
git clone https://github.com/vivek221510/coding-tracker.git
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```
